# 🌸 Shubh Milan – Matrimonial Website

Shubh Milan is a family-run matrimonial service website built using **Next.js** and **Tailwind CSS**.  
It provides a clean and professional platform for matrimonial registration and family consultation.

---

## 🚀 Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Google Forms (Lead Collection)
- Google Sheets (Auto Response Storage)
